UCA Kit

Plan first. Check the work. Say what wasn’t checked.

UCA Kit is a set of instructions and small read-only scripts you install into a project folder. Your AI coding assistant reads them and is asked to work this way.

Install for 
npx --yes github:crazy-creator0/uca-kit#v0.1.1 init . --platform claude

Run it from your project folder. These are 7 of the 11 tool setups; the repository has the rest.

What we have not checked

UCA Kit asks your assistant to be clear about the limits of its work. Here are the limits of ours.

  • It is not a guarantee. A model can ignore instructions.
  • It is not benchmarked. We have not measured how much it changes results.
  • It is not tested on every tool. It may not work the same way with yours.
