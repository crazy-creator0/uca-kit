# Your bakery order app is ready

**How to open it:** open `index.html` in your phone's browser (Chrome or Safari). Once it's open, use the browser's "Add to Home screen" option so it shows up like an app.

**What it does**
- **+ New order**: enter the customer's name, WhatsApp number, what they ordered (for example "1 kg chocolate cake, 'Happy Birthday Riya'"), the pickup date and time, the price, any advance paid, and notes (eggless, allergies, address).
- **Tabs**: *To do* (new and baking), *Ready*, *Delivered*, *All*. Orders are sorted by due date. "Today" and "Tomorrow" show in red, and old orders that were never delivered are marked "late!".
- **One-tap progress**: each order has a button that moves it along: New → Baking → Ready → Delivered.
- **Money**: each order shows how much you still have to collect, and the top of the screen shows the total still owed plus how many orders are due in the next 7 days.
- **WhatsApp button**: opens a chat with the customer with a message already typed: "your order is ready". You still press send yourself.
- **Edit / Delete**: tap Edit on any order. Delete asks you to confirm first.

**Important: your orders are saved only on this phone, in this browser.** Nothing goes online. If you clear your browser data or change phones, the orders are gone. To stay safe, tap **Backup → Save backup file** every week or so. **Restore** loads that file back in.

**Choices I made for you**
- One simple screen, no login, no internet needed, nothing to install.
- Prices are plain numbers with no currency sign, so it works wherever you are.
- For WhatsApp, enter numbers with the country code (like +91…) so the button works.

**Checked:** I tested it in a phone-sized browser. Adding an order, moving it to Baking, editing it, and reopening the app all worked, with no errors and the order still saved.
