# UCA Kit

Read root `AGENTS.md` before substantial changes.

Skills are in `.agents/skills/<name>/SKILL.md`. If your selected agent supports the Agent Skills standard, use its documented discovery path; otherwise open the needed file directly. Open only the skill the task needs.

If a feature is missing, do specialist work one step at a time; `HOST-CAPABILITY-FALLBACK.md` has details when it is installed. Do not assume every assistant in the IDE behaves the same. Never claim automatic usage metering without verified support. Merge with existing project rules instead of overwriting them.
