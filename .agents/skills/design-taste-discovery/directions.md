# Design directions — read when writing the brief (Step 3)

Starting points, not templates. Pick two that fit the domain, choose one, then change at least two attributes with real objects or words from the domain, add a signature element, and one deliberate departure. Using a direction unchanged is a failure of the brief. Fonts are free families; check the licence you actually use.

## Ledger
- **Fits:** money, invoices, admin, accounting, offices, school records.
- **Type:** Newsreader (headings, body), IBM Plex Mono (figures).
- **Color:** paper #F4EFE6, ink #1D1B16, rule #C9BFA9, stamp #B3261E.
- **Shape:** 2px radius, 1px rules instead of cards, no shadows.
- **Layout:** one wide ruled table leads; the entry form is a single row above it.
- **Signature idea:** a rubber-stamp status mark (PAID, LATE) in the stamp color.
- **Motion:** none beyond a row highlight.
- **Avoid:** stat-card rows, rounded panels, gradients.

## Chalkboard
- **Fits:** cafes, food, bars, menus, specials, classes.
- **Type:** Fraunces (display), Work Sans (body).
- **Color:** slate #22282A, chalk #EDE9DD, accent #E8B04B, muted #8A9496.
- **Shape:** 4px radius, dashed chalk rules, no shadows.
- **Layout:** the board is the screen: items in columns with leader dots to prices.
- **Signature idea:** an item scratched off when sold out.
- **Motion:** quick chalk-wipe on change.
- **Avoid:** photos of coffee cups as decoration, pastel cards.

## Ticket rail
- **Fits:** kitchens, counters, queues, dispatch, support desks, point of sale.
- **Type:** Archivo (heavy), JetBrains Mono (times and numbers).
- **Color:** white #FAFAF7, black #111111, new #1F6FEB, late #D1242F, done #2DA44E.
- **Shape:** square corners, 3px status edge on each ticket.
- **Layout:** tickets in a horizontal rail ordered by age; the oldest is largest.
- **Signature idea:** a running timer that changes the ticket edge color.
- **Motion:** none; state change is instant and loud.
- **Avoid:** small touch targets, hover-only actions.

## Field notebook
- **Fits:** habits, journals, plans, personal tools, study, small shops.
- **Type:** Instrument Serif (headings), Public Sans (body), IBM Plex Mono (labels).
- **Color:** page #FBF7EE, ink #26241F, margin #D9544D, highlight #F6E27F.
- **Shape:** 0 radius, a ruled page, a left margin line.
- **Layout:** one column like a page; today is written at the top, history below.
- **Signature idea:** items are ticked with a hand-drawn SVG mark, not a checkbox.
- **Motion:** the tick draws itself.
- **Avoid:** dashboards, progress rings.

## Swiss grid
- **Fits:** data, reports, schools, timetables, directories, portfolios.
- **Type:** Space Grotesk (all), tabular numerals.
- **Color:** white #FFFFFF, black #0A0A0A, one signal #E63312, grey #6B6B6B.
- **Shape:** hard grid, 1px black rules, no radius.
- **Layout:** a 12-column grid with oversized numerals as the headings.
- **Signature idea:** the key figure set at poster size, everything else small.
- **Motion:** none.
- **Avoid:** icons in circles, equal-weight cards.

## Control room
- **Fits:** monitoring, operations, developer tools, logistics, dense data.
- **Type:** JetBrains Mono (data), Inter Tight (labels).
- **Color:** bg #0E1116, panel #151A21, text #D6DCE5, ok #3FB950, warn #D29922, fail #F85149.
- **Shape:** 3px radius, 1px borders, no glow.
- **Layout:** dense rows with sticky headers; a single status strip at the top.
- **Signature idea:** a status LED per row, never decoration.
- **Motion:** only on value change, 150 ms.
- **Avoid:** glowing gradients, large empty hero areas.

## Poster
- **Fits:** events, games, portfolios, campaigns, kids, creative studios.
- **Type:** Bricolage Grotesque (huge), DM Sans (body).
- **Color:** a flat field #FFD23F, black #111111, pink #FF5D8F, blue #3A86FF.
- **Shape:** thick 3px outlines, offset hard shadows, 12px radius.
- **Layout:** big type crops off the edge; one sticker-like action.
- **Signature idea:** one rotated label that carries the main action.
- **Motion:** a single springy entrance, then still.
- **Avoid:** purple gradients, centred hero plus three cards.

## Clinic calm
- **Fits:** health, booking, care, schools for small children, accessibility first.
- **Type:** Atkinson Hyperlegible (all).
- **Color:** bg #F7F9F8, text #14211C, accent #0F6E5C, soft #DCEBE6, alert #B42318.
- **Shape:** 8px radius, 44px minimum targets, visible focus rings.
- **Layout:** one task per screen, the next step is always the largest button.
- **Signature idea:** a plain-language summary line that restates the user's choice.
- **Motion:** none required; respect reduced motion.
- **Avoid:** tiny grey text, icon-only buttons.

## Workshop catalog
- **Fits:** inventory, parts, tools, shops, warehouses, equipment rental.
- **Type:** Barlow Condensed (labels), IBM Plex Mono (part numbers).
- **Color:** steel #E6E8E3, black #151515, safety #FF6A13, stock #2E7D32, out #C62828.
- **Shape:** 0 radius, label-maker tags, 2px borders.
- **Layout:** a catalog table with a stock bar per row; scanning beats browsing.
- **Signature idea:** every item has a printable shelf label view.
- **Motion:** none.
- **Avoid:** product-card galleries without quantities.

## Garden almanac
- **Fits:** plans, recipes, seasons, wellness, farms, calendars, slow tools.
- **Type:** Young Serif (headings), Source Sans 3 (body).
- **Color:** soil #2F2A24, leaf #4F6F52, cream #F3EEDC, bloom #D77A61.
- **Shape:** 10px radius, hand-cut leaf-edge dividers, soft borders.
- **Layout:** time leads: the season or week is the frame, entries hang from it.
- **Signature idea:** a seasonal accent that shifts with the date.
- **Motion:** slow fades only.
- **Avoid:** neon accents, glass panels.
