How to read this

This is one run per side, and the same model wrote both. The scores are close, and in this run the kit did not produce tests. An earlier run with different instructions produced a with-kit build with 14 tests, so results vary from run to run. The Senior Bar check is the kit's own checklist. It does not say which app is better to use. Open both and judge for yourself. Both keep records inside your browser only, so nothing here is sent anywhere.

The exact request, the answers given to questions, and the closing question are in PROMPT.md. Neither app has been tried on a real phone by anyone. To repeat the run, follow the steps in PROMPT.md.
