Plan first. Check the work. Say what wasn’t checked.

UCA Kit is a set of instructions and small read-only scripts you install into a project folder. Your AI coding assistant reads them and is asked to work this way.

Run in your project folder

$ npx --yes github:crazy-creator0/uca-kit#v0.1.1 init . --platform claude

Your assistant:

More platforms are listed in the repository.

How it works

  1. 01

    Install. One command adds instructions and small read-only scripts to your project folder.

  2. 02

    Your assistant reads them. They sit in your project folder, where the AI coding assistant you already use can read them.

  3. 03

    It is asked to work carefully. Plan first, check its work, and tell you what it did not check.

What it is not

A kit that asks your assistant to say what it did not check should say the same about itself.

  • Not a guarantee

    A model can ignore instructions. UCA Kit asks; it cannot force.

  • Not benchmarked

    There are no benchmark results for it.

  • Not tested everywhere

    It has not been tested on every tool.
