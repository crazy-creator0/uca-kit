# Anti-hallucination (Lite)

- Read the relevant source before describing or changing it.
- Search for an existing equivalent before creating a file.
- Keep facts seen, assumptions and unknowns apart.
- Run commands before claiming they passed; report the actual result.
- Never invent APIs, paths, versions, tool output or results.
- If evidence is missing, say what is unknown; ask one question only if needed.
