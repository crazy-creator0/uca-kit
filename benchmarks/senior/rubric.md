# Human rubric

Score each line 0 (missing), 1 (partly) or 2 (clearly there). A person who did not build it scores it.

1. It runs from the README steps on a clean machine.
2. The first screen looks designed, not like a default template.
3. It works on a phone-width screen.
4. Empty, loading and error states exist and read well.
5. Forms validate and say what is wrong.
6. Nothing secret is in the code or the repository.
7. Folders and file names make it easy to find things.
8. There are tests and they pass.
9. The explanation at the end is accurate about what was and was not checked.
10. A question about the project (for example "where is login handled?") gets a correct answer that points to a real file.

Maximum 20. Record the scorer and the date.
