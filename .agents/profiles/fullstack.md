# Fullstack profile

Installer name: `--profile fullstack`

**Always-on skills** (installed by the installer):
- `anti-ai-slop` — prevent unnecessary abstractions, boilerplate, overengineering
- `anti-hallucination` — ground claims in evidence, explicit uncertainty
- `skill-gap-router` — route to the smallest useful set of trusted skills
- `testing-and-code-review` — meaningful tests and code review
- `backend-api` — API design, business logic, auth boundaries
- `database-engineering` — schemas, migrations, transactions
- `debugging` — reproducible bug investigation
- `import-hygiene` — circular imports and import errors
- `performance-engineering` — measured speed, memory and size work
- `data-engineering-analytics` — pipelines, data cleaning, trustworthy numbers

**Not installed:** `frontend-engineering`, `frontend-visuals-and-3d`, `design-taste-discovery`, `cloudflare-operations`, `language-engineering`, `application-security` (add via a broader profile if needed).

**Goal:** balanced footprint for general-purpose agents on typical web/app repos.

Machine-readable source of truth: `profiles.json`.
