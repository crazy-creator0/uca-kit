# Audit report: Private PDF Editor

Date: 2026-11-24. Workflow: `.agents/workflows/audit.md` (read-only). No project file was changed; this report is the only new file.

## What was audited
- **Stack:** a static web app with no server code. `index.html`, `styles.css`, `sw.js` (offline cache), `manifest.webmanifest`, and ES modules `js/app.js`, `js/export.js`, `js/fonts.js`, `js/store.js`, `js/textdraw.js`. pdf.js and pdf-lib are in `vendor/` (not reviewed line by line). Tests are in `tests/`.
- **Goal it is measured against:** the original request: "editing content on the page without sending data to anyone, supporting most fonts, unlimited editing, with more features than Sejda's PDF editor."
- **How:** kit scripts, reading every file under `js/` plus `index.html`, `sw.js`, and `README.md`, running the project's own test suite, and running a probe script in headless Chrome. The tests and probe ran on a copy in `/tmp`, so the project's `.uca-workspace/out` was not overwritten.

## Kit checks (step 2)
- `node scripts/uca-readiness.cjs .` gave **Silver**, 25 of 26 checks (96%). The target (Silver and 80%) is **met**. The one failing check is Gold, "The runtime version is declared": there is no `engines`, `.nvmrc` or `.python-version`.
- `node scripts/uca-audit-check.cjs . --json` scanned 20 files and skipped 14 (tests, fixtures). It found **0 findings**, so there were no "needs a human" items to sort.
- `node scripts/uca-wiring-check.cjs . --json` found 1 page, 3 links, no router and **0 findings**. No link's words point to a different page. No saved link map exists, so there was nothing to compare.
- `node tests/e2e.mjs` (the project's own test, run on a copy) ended with **"All checks passed"** (36 checks). That includes "no request left this computer during all tests", a 300-page file, offline reload, and erasing for real.

The static checks are clean, but every finding below came from reading the code or running it.

## Lenses where nothing was found (what was looked at)
- **Sending data anywhere:** the CSP (`index.html:6`) allows only `'self'`, `blob:` and `data:`. There is no `fetch` in `js/`, and `sw.js` only handles same-origin GETs. The e2e test logged 234 requests, all local. **No finding.**
- **Script injection:** there are no `innerHTML`, `eval` or `new Function` calls in `js/`. File names, PDF text and font names reach the page only through `textContent`, `new Option` or quoted, sanitized font strings (`textdraw.js:395`, `fonts.js:77`). pdf.js runs with `isEvalSupported: false`. **No finding.**
- **Who may do what / server routes / database / paid APIs:** none exist. This is a static app that costs only static-hosting bandwidth (about 2.3 MB on the first visit, then cached by the service worker). **Nothing to check.**
- **Original file safety:** the original bytes are only copied (`.slice()`). The e2e test confirms the file on disk stays byte-for-byte the same. **No finding.**
- **Links and the way back:** there is one page. Dialogs close with Close or Cancel, Find has Close, and "Show original" toggles back. **No finding.**

## Could not decide / not covered
- Whether erasing leaves text in tagged PDFs or form fields (see the Medium "cannot tell" row).
- How it behaves with RTL scripts, right-to-left page layouts, and Chinese, Japanese and Korean input methods inside the text box: not run.
- Lag was measured only by the project's test (300 pages: 0.5 s to first page, 0.6 s to save). Very large files (thousands of pages, hundreds of MB) were not tried. Note that `openBytes` reads every page's size one by one before showing anything (`app.js:72-76`), and the file is held in memory about 3 to 4 times at once (original, worker copy, storage copy, pdf-lib copy at save).
- Safari and Firefox were not run; only Chrome was.
- The `vendor/` libraries were not reviewed or checked for known flaws. There is no internet access here to compare versions.
- "More features than Sejda": a feature-by-feature comparison was not part of this audit.

## Fix plan (waiting for your approval; nothing has been fixed)
The readiness target is already met (Silver, 96%). The plan covers the High finding and the Medium ones. Before any page or link change, save the link map with `node scripts/uca-wiring-check.cjs . --save .uca/wiring.json`.

1. **Find and replace runs twice** (High), in `js/app.js` (`doFind`, `replaceAll`). Test first: the "Find clicked twice" probe (it should report 300 and no `fox!!`). Could break: progress text during a search. Afterwards: probe, `npm test`, readiness.
2. **"Save as pictures" sticks to later files** (Medium), in `js/app.js` (`openBytes`, `runSave`), next to fix 1 because it is the same file. Test first: the forced-failure probe (the healthy file should keep its text). Could break: the retry button after a real failure. Afterwards: probe, `npm test`.
3. **Password removed on save** (Medium), in `js/app.js` (`openSaveDialog`) and `index.html` (warning text). **Your decision:** warning only, or also add a library that can re-encrypt (a new dependency, so it needs your OK). Test: the password-file probe checks that the dialog names it.
4. **Stored copy of the PDF** (Medium), in `js/app.js` (`start`, the restore panel, after save), `js/store.js`, and `index.html` (wording). **Your decision:** keep the backup with clearer wording and an always-visible Forget, or clear it after save, or make it opt-in. Test: the open → save → reload probe.
5. **Cover is not redaction by default** (Medium), in `index.html` and `js/app.js:805`. **Your decision:** tick "erase" by default, or rename the tool. Test: the existing e2e erase checks.
6. **Erase leftovers in tagged and form PDFs** (Medium, unconfirmed), in `js/export.js` plus a new test PDF in `.uca-workspace/pdfs`. Confirm first with a tagged and a filled-form PDF; fix only if confirmed. Could break: bookmarks to erased pages.
7. **Keyboard and screen-reader use** (Medium), in `js/app.js` (`renderRuns`, `renderEdits`, keyboard handler), `styles.css` (focus ring), and `index.html:17` (the `radiogroup` Low item, same area). Test: a Tab-through check that the first text run can be edited with Enter. Could break: clicking and dragging on pages, so run the full e2e.
8. **Low items** (undo memory, double encoding, temporary canvas, `__editor`, restore matching by size, RTL `dir`, `engines`). These are small, one at a time, and the order is your choice.

Each fix follows the Safe Vibe Loop: offer a checkpoint, make one change, run its test plus `node scripts/uca-readiness.cjs .` and `npm test`, then report.
