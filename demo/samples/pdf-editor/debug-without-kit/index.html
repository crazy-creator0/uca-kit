Edit a PDF without sending it anywhere

Everything happens inside this browser window. Your file is never uploaded, and the original is never changed: you always save a new copy.

or drop a PDF file anywhere on this window

  1. Change text: click any words on the page and type.
  2. Add text: pick "Add text", then click where it should go.
  3. Sign, add pictures, highlight, draw, add links and fill forms with the tools on the left. Each page has buttons to turn, move, delete or add a page.
  4. Any font, any language: use fonts on your device, or add a font file (.ttf, .otf, .woff).
  5. Save a copy: you get a new file; the original stays as it was.
