# Fee Book

A phone-friendly page for tracking monthly student fees. No server, no install.

## Start it
1. Keep `index.html` in any folder on your phone or laptop.
2. Open it in Chrome or Safari (on a phone: Files app, then tap `index.html`, choose the browser).
3. Tap "+ Add student" and enter name, monthly fee, and the month fees start counting.

## Keep your data safe
Records live in the browser on that device only. Clearing browser data, or opening the file in a different browser, shows an empty book. Tap "Save backup file" regularly and keep the file somewhere safe. "Restore from backup" brings it back.

## Test (developer only)
`node .uca-workspace/test.cjs` drives headless Chrome through the main journeys.
