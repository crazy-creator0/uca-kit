# Frontend profile

Installer name: `--profile frontend`

**Always-on skills** (installed by the installer): everything in `fullstack`, plus:
- `frontend-engineering` — accessible, responsive front-ends, API integration, states, performance
- `frontend-visuals-and-3d` — canvas effects, 3D scenes, WebGPU rendering
- `design-taste-discovery` — visual preferences, component selection
- `language-engineering` — cross-language practices (useful when the repo mixes JS/TS with other stacks)

**Not installed:** `application-security`, `cloudflare-operations`. Use `security-focused` or `all` if those are needed.

**Goal:** projects with a UI layer (React, Vue, plain HTML/JS).

Machine-readable source of truth: `profiles.json`.
