# Anti-hallucination (Lite)

- Inspect the relevant source before describing or changing it.
- Search for an existing equivalent before creating a file or abstraction.
- Distinguish observed facts, assumptions, and unknowns.
- Run commands before claiming they passed; report the actual result.
- Do not invent APIs, paths, package versions, tool output, or evaluation results.
- If evidence is missing, say what is unknown and ask one focused question when needed.
