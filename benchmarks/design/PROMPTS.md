# The eight prompts

Give each prompt, unchanged and with no extra hints, to the agent with the kit installed. One prompt per fresh session. Save every result in its own folder named `<prompt-number>-<variant>` (variant = a label you choose such as `main-modelA`).

1. create cafe management file
2. build a booking site for my yoga studio
3. make a school management system
4. I need an admin dashboard for my bakery
5. create a simple expense tracker app
6. make a habit tracker for my phone
7. create a CRM for my freelance work
8. design a website for my dental clinic

Why these: they are short, name a domain, and say nothing about style or tools, which is the case where output has fallen back to generic templates. Add your own prompts if you like; keep the same rubric.
